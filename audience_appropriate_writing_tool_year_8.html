Year 8 Scientific Communication Toolkit:

1. FIGURE NAMES Reference Data

Always name the graph in your text (e.g., "As shown in Figure 1...").

2. SI UNITS Precise Data

Pair every number with correct units (e.g., bpm, °C, seconds, cm, Watts).

3. AUDIENCE TONE Scientific Register

Use Year 8 terms (e.g., plateau, kinetic energy, directly proportional, rate).

4. CITATIONS APA Referencing

In-text: (Author, Year) + Full APA reference listed at the end.
